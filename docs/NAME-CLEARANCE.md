# Name clearance: "Slipstream" / "Slipstream Browser"

Five-angle sweep (trademark registers, software products, browser space,
distribution channels, domains/web) run 2026-08-30 by parallel research
agents; 111 raw findings. This is research, **not legal advice** — a
trademark attorney knockout search is the gold standard before v1.0.

## Verdict

- **"Slipstream Browser" (compound): CLEAR to ship v0.1.** No web browser —
  active, dead, or historical — has ever shipped under the name on any
  platform checked (Google Play, Apple App Store, Microsoft Store, the
  Chromium/Firefox fork ecosystem, Wikipedia's browser lists, winget, Scoop,
  Chocolatey). The only repo ever claiming "Slipstream web browser" is an
  empty abandoned GitHub shell.
- **"Slipstream" (bare): usable with caution.** Heavily reused across
  software (VPN/DNS tunnel, Elixir library, DeFi contracts, a Steam racing
  game, dead PaaS, dead npm/PyPI squats) — but nothing browser-class is
  alive, and the term's generic Windows-jargon use ("slipstreaming updates")
  dilutes anyone's exclusive claim in this space. Brand consistently as
  **Slipstream Browser** in titles, store listings, and metadata.

## Findings that matter, ranked

1. **SlipStream Data Inc.** (dead, highest historical adjacency) — Waterloo
   company whose web accelerator was integrated into the Opera browser in
   2004; acquired by RIM/BlackBerry July 2006 and absorbed. Brand dead ~20
   years; no evidence of live marks in active use. The one prior commercial
   "SlipStream"-next-to-a-browser use. **Low risk** (dead brand, no
   marketplace presence, likelihood of confusion ≈ nil).
2. **NAT Slipstreaming** (Samy Kamkar's 2020–21 browser-delivered attack) —
   not a trademark issue at all, but the dominant result for
   "slipstream + browser" in security contexts. For a security-positioned
   browser this is an SEO/association quirk to be aware of, not a blocker.
   FAQ-worthy ("no relation to the attack technique").
3. **Active small-scale users of the bare name** — SlipStream VPN/DNS-tunnel
   ecosystem (active, networking-adjacent), "Slipstream Live" Chrome
   extension (14 users), a dormant aviation-logbook extension named exactly
   "Slipstream" in both extension stores, slipstream.app (Australian
   trucking SaaS), the Steam racing game. Different goods, tiny audiences,
   or dead — **low risk individually and collectively**.
4. **Slipstream Communications LLC** USPTO serial 77469589 — abandoned 2013,
   no statement of use. Dead.

project presence (GitHub, site on a compound domain, store listings).

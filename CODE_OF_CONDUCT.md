# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**TL;DR**: Be respectful. Harassment, personal attacks, and bad-faith conduct
get you removed. Technical disagreement is welcome; hostility is not.

Enforcement contact: open a report via GitHub's private reporting on this
repository. The maintainer reviews all reports and will act within 7 days.
